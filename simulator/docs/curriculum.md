## Replacement and reset policy

At the user's request, older bank versions are no longer resumable. Any attempt whose exam code or bank version differs from the running release receives `409 exam_reset`; its cookie is cleared and its old questions, report and certificate are not returned. A fresh attempt requires name entry and starts with blank answers, flags and lab state, and a new 90-minute deadline. Existing database records/backups are retained operationally but cannot serve the retired form through the app.

Writes carry the loaded attempt ID and bank version. This prevents an already-open old tab from writing into a new attempt through shared cookies. Such rejected writes do not delete the fresh attempt's cookie. The refreshed frontend clears pending autosaves on reset and checks for a changed bank on return to the tab and every 30 seconds while visible and idle. Tabs still running an earlier frontend must reload; the server rejects their stale writes immediately.
